# R1 `plc_read` implementation plan

Design: [2026-09-25-r1-plc-read-design.md](../specs/2026-09-25-r1-plc-read-design.md)
Branch: `feature/r1-plc-read` (stacked on `feature/r0-object-read`)

## Global constraints

- Reuse R0: the DomainReads framework on the host, and the Siemens-free `ObjectModel` core
  (`IObjectNode`, `ObjectPathResolver`, `OffsetCursorCodec`) in the worker. No second addressing,
  paging, validation, or decoding mechanism.
- Every listed object carries an R0 `objectPath`.
- Only the method-based reads (block fingerprints, comparison) use typed Siemens APIs; everything
  else runs over `IObjectNode` and is tested on in-memory graphs.
- Live evidence only from the read-only acceptance run (Task 6).

## Tasks

1. **Generic core additions** (`TiaMcpServer.OpennessWorker/ObjectModel/`): `IObjectNode.ReadValue`
   (dynamic attribute, else public CLR property), `ObjectScalarNormalizer` (JSON scalars, enum
   symbols, ISO dates, versions, short arrays), `ListPager`, `GroupTreeLister` (depth-first group
   hierarchies with group paths and object paths). Contracts `DomainObjectInfo`, `DomainEntryInfo`.
2. **PLC core** (`TiaMcpServer.OpennessWorker/PlcRead/`): `PlcLocator` (Devices + DeviceGroups,
   nested device items, exact-one selection), `PlcReadBuilder` (listing specs, table entries, TO
   parameters, checksums).
3. **Siemens handlers**: `Openness/PlcReadService.cs` (`FingerprintProvider.GetFingerprints`,
   `PlcSoftware.CompareTo` flattening), worker dispatch, 14 `Observe` policy entries, protocol
   capability `plc-read`.
4. **Host**: `TiaMcpServer/PlcRead/` request, catalog, invoker, payload contract, tool;
   registration in both modes; `ApprovedToolSurface` census for the surface tests.
5. **Tests**: locator, normalizer, lister/builder on an in-memory project; catalog matrix; payload
   contract; FakeWorker end-to-end.
6. **Docs and live acceptance**: `PLC_READ_SUMMARY.md`, architecture/README/guide counts, roadmap,
   read-only acceptance report on `test.ap21`.
