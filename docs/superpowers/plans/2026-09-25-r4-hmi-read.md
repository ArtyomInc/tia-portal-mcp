# R4 `hmi_read` implementation plan

Design: [2026-09-25-r4-hmi-read-design.md](../specs/2026-09-25-r4-hmi-read-design.md)
Branch: `feature/r4-hmi-read` (stacked on R3)

## Tasks

1. **Core addition.** `IObjectNode.ReadObject` for object values whose declared type is an interface
   (`IHmiScript`).
2. **Pure builder.** `HmiRead/HmiReadBuilder.cs`: HMI locator over `DeviceWalker` (Unified
   `HmiSoftware`, Classic `HmiTarget`), exact selection, per-runtime listing specs, screen items,
   screen scripts.
3. **Wiring.** `HmiReadInfo.cs`; `WorkerRequest.HmiName`; 10 `Observe` entries; capability
   `hmi-read`; worker dispatch (no typed Siemens calls — the WinCC assemblies stay reflection-only).
4. **Host.** `TiaMcpServer/HmiRead/HmiReadTools.cs` (request, catalog, invoker, contract, tool);
   registration; census 18/8.
5. **Tests.** In-memory Unified and Classic HMIs (runtimes, groups, Classic tag tables, capability
   gaps, screen items, scripts); catalog; contract; FakeWorker end-to-end.
6. **Docs and live acceptance** (combined R3–R5 read-only run).
